Latência por operação

Os nomes são os passos internos do agente (LangChain e LangGraph), registrados no Langfuse. As rotas da API (/chat, /upload...) ainda não aparecem aqui.

Custos vêm do Langfuse, em dólar, e são convertidos para reais pela cotação de venda do PTAX (Banco Central). Modelos sem preço cadastrado no Langfuse aparecem com custo zero.
